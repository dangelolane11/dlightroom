# Brand files

DLightroom does not use the ArtCraft name, wordmark or logos. The upstream VectorCraft repository
kept them here under [`LICENSE-brand.txt`](LICENSE-brand.txt), whose "Forks and modified versions"
section requires a modified version to remove them. They have been removed from this fork; the
licence text is kept unchanged as part of the upstream licence material.

DLightroom's own app icon is original artwork in [`assets/app-icon/`](../../assets/app-icon/README.md).
